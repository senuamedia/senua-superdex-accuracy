# Change log

Every change to code in this repository: the patches to SuperDex, the rigs and play scripts, and the measuring
programs. Each row names the study it belongs to: the registration or run it was made for, or the pass it was part of.

Results are not listed here. They are on [the study pages](studies/README.md).

Back to the [documentation index](README.md).
